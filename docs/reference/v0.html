JobMap AI

Geospatial job intelligence · Jun 2026
Live front end
Problem
Job boards tell you the title and the company. They do not tell you whether the role actually matches your resume, or where it sits relative to where you live.
Approach
A Next.js and Mapbox GL front end over a FastAPI backend running two LangGraph pipelines, one that parses postings and one that matches resumes, with pgvector HNSW similarity search, Nominatim geocoding, and real listings from the JSearch API on Neon Postgres.
Result
Roles plotted on a map and ranked by semantic fit instead of keyword overlap, with relevant matches surfacing in under a second despite wording mismatches between a resume and a posting. Getting there meant dropping PostGIS for plain lat and lng columns to survive an IPv6 deployment constraint, and replacing SQL LIKE filtering with vector similarity.

Wellness Search Engine

Semantic search · May 2026
GitHub
Problem
A 143,000 page wellness crawl ranked with a classical TF-IDF vector space model. It matched keywords well and answered questions badly, so the top results were often on topic and still useless.
Approach
I rebuilt the retrieval stack end to end: hybrid BGE-M3 dense and sparse retrieval over a FAISS HNSW index, cross encoder reranking on the shortlist, PageRank and HITS as authority signals, KMeans topic clustering, and LLaMA through Groq for query expansion and answer generation.
Result
Roughly 0.8 second queries across the full collection, served through a three panel interface that puts my results next to live Google and Bing so the ranking has to defend itself.

AI-Assisted GPU Kernel Generation

Graduate research · Sep 2025
Problem
Parallel reductions are nondeterministic. Change the concurrency and the same input gives a different answer, so a kernel can be fast and quietly wrong, and the error only surfaces once it is deep inside a model.
Approach
Wrote both deterministic and atomic Triton kernels for the same reductions and measured the drift between them in max ULP difference, then built a logging and benchmarking harness to tie execution configuration to performance and numerical stability together.
Result
Up to 34 ULP of variation across configurations, which puts a number on a trade-off that usually gets described in adjectives. Useful for anyone deciding how much reproducibility an inference path can afford to give up.

Kidney Disease Classification

Deep learning · May 2025
Problem
Classifying kidney disease from CT scans is the easy half. The hard half is making the pipeline reproducible, so a result from three weeks ago can still be explained and repeated.
Approach
An end to end pipeline in TensorFlow and Keras, with modular training and evaluation stages driven by YAML configuration, DVC for data versioning, MLflow for experiment tracking, and automated evaluation and deployment through Flask on AWS EC2.
Result
87.1 percent validation accuracy at 0.30 loss, and more usefully, every run traceable back to the exact data and configuration that produced it.
